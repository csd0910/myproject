## ここから下をコピーしてAntigravity 2.0に送信

あなたは優秀なC#（.NET Framework）エンジニアです。
Windows XP（SP3）環境で動作する、超軽量な「タスクマイニング用データコレクター」のベース（大枠）コードを作成してください。

### 【背景と目的】
既存のPythonベースの分析エンジン（DX_Reverse_Engineering_Engine）に食べさせるための操作ログデータを、完全オフラインのWindows XP端末から抽出することが目的です。
XP端末ではAI解析や重い処理を一切行わず、以下の「ユーザーの操作状況」だけをWin32 APIなどを用いて軽量に監視し、CSVに書き出します。

### 【開発環境・要件】
*   **対象OS:** Windows XP SP3
*   **使用言語:** C# (.NET Framework 4.0 または 2.0)
*   **アプリ形態:** Windows Forms（タスクトレイ常駐型）または Consoleアプリケーション
*   **外部ライブラリ:** 原則使用不可（標準の .NET ライブラリと Win32 API のP/Invokeのみで実装）

### 【取得・出力するCSVの形式（要件）】
ウィンドウや状態が切り替わったタイミングで、以下のカラムを持つCSVに追記してください。
1. **開始日時** (yyyy/MM/dd HH:mm:ss)
2. **終了日時** (yyyy/MM/dd HH:mm:ss)
3. **滞在時間** (秒)
4. **状態** (作業中 / 離席中 ※5分無操作で離席判定)
5. **アプリケーション名** (例: EXCEL.EXE)
6. **ウィンドウタイトル** (例: 週次報告書.xlsx - Excel) ※ダイアログボックスなど子ウィンドウの変化も検知すること
7. **打鍵数 / マウスクリック数** (その作業期間内の合計入力回数)
8. **クリップボード転記内容・形式** (テキストなら先頭50文字。画像やファイルの場合は [画像データ] [ファイル] 等と形式を記録)

### 【必要なWin32 APIの想定】
*   `GetForegroundWindow`, `GetWindowText`, `GetWindowThreadProcessId` (アクティブウィンドウ取得)
*   `GetLastInputInfo` (離席判定用)
*   `SetWindowsHookEx` (WH_KEYBOARD_LL, WH_MOUSE_LL) (打鍵数・クリック数のカウント用。※何のキーを押したかの生ログ保存は不要、回数のみ)
*   Clipboard API (クリップボード監視用)

### 【今回の依頼】
上記を満たすための **全体構成（クラス設計）** と、その中核となる **メインロジック（Program.cs, メインとなる監視クラスの実装）の初期コード** を出力してください。
特にWin32 API呼び出し部（P/Invoke）と、ポーリング監視ループの骨組みを最優先でお願いします。
