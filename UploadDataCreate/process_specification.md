# CSV加工・アップロード用データ作成 業務フロー・仕様書

本ドキュメントは、現場で実行されているExcel上の手作業によるデータ加工プロセス（吹き出しやコメントから抽出した手順）と、自動化に向けた「今後の改良」を整理した統合版仕様書です。

## 1. 前提
* **ベースとなるファイル**: `result_260812_135942.xlsx` （大元のSheet1をベースに作業）
* **利用するマスタ/補助ファイル**:
  * `【2】社外キーワード追加対応.xlsx`
  * `111取り寄せ＋有効在庫有り.csv`
  * `111倉庫_売価変更用.csv`
  * `イベント別キーワード一覧` （※自動化に向けてUI/ファイル名などで動的参照するデータ）

---

## 2. 前処理・除外処理
1. **更新除外データの削除**
   - **参照**: `【2】社外キーワード追加対応.xlsx` の「更新除外シート」
   - **処理**: ベースデータ（こっち側）の **C列（品目cd）、D列（注文番号）** と、参照先（向こう側）の **B列、D列** をキーとしてVLOOKUPを行い、一致する行を行ごと削除する。（原文：「こっちにある中から向こうにあるものを削除」）

2. **取り寄せ品の除外（工程2〜5の統合）**
   - **参照**: `111取り寄せ＋有効在庫有り.xlsx`（または.csv）
   - **処理手順**:
     1. 【工程2】参照ファイルを開く。
     2. 【工程3】**C列（有効在庫数）**でフィルターをかけ、数値が `0` のものを行ごと削除する。
     3. 【工程4】**G列（未引当て数量）**でフィルターをかけ、数値が `1` 以上のものを行ごと削除する。
     4. 【工程5】上記フィルター後に残ったデータをベースデータの **C列（品目cd）** と照合し、一致する行をベースデータから除外（削除）する。

3. **医薬品の除外**
   - **対象**: ベースデータの **AG列**（品目大分類cd）
   - **処理**: フィルターで「40番」（医薬品）を抽出し、該当する行を除外（削除）する。

4. **特定文字列の削除**
   - **対象**: 商品名等の文字列項目
   - **処理**: 文字列内にある `【一医１】` および `【管医１】` を検索し、置換で空白にする（削除）。

---

## 3. 文字列操作・条件付与
1. **「送料無料」の付与（楽天のみ作業）**
   - **参照**: `111倉庫_売価変更用.csv`
   - **処理**: ベースデータの「注文番号」と、参照ファイルの **F列** でVLOOKUPを実行する。売価変更用の **F列に「2」が当たった** 注番でフィルターをかけ、商品名（**「足し算」列 / U列**）の頭に `送料無料 `（後ろに半角スペース付き）を付与する。
   - ※備考: 元データ抽出段階で倉庫品コードが抽出できれば、わざわざVLOOKUPの必要はない。

2. **イベント別キーワードの付与（楽天のみ作業）**
   - **【現状の手作業】**
     - これまで作業してきたすべての商品が入っている元データをコピーして、新しいシートを作る。
     - コピーしたものに対し、イベントごとに対象商品の「注文番号」同士でVLOOKUPをあてる。（※対象商品はイベントごとに色々なところから参照しており、決まった場所から参照はしていない）
     - VLOOKUPをして当たった注文番号以外（N/A）の行を削除し、対象のイベントだけに絞り込む。
     - イベント用のキーワードを商品名（「足し算」列 / U列）の頭に付与する。

   - **【今後の改良（自動化の仕様）】**
     - 「食わせる目玉商品」などのキーワードは、別CSVで `注文番号_キーワード` のデータを作成する。
     - resultのファイルでは大元のSheet1をそのままコピーする。
     - UIまたはJSONから「イベント名（お買い物マラソン、目玉商品など）」を任意に設定・分割する。
     - **ファイル名・シート名での動的処理**: resultのシート名と、食わせるファイルのシート名（イベント名）を同じにして、ファイル名ベースで処理を実行する。
     - イベントと紐づけて、**U列の「足し算」**の頭にキーワード（例: `【目玉商品】 `等、後ろに半角スペース）を自動で付加する。
     - **「付加したデータ（行）のみ」**を抽出し、追加したデータ以外は削除したものを、CSVと同じ `イベント名` のシート名で新たに書き出す。

3. **文字数制限の調整（楽天: 255バイト制限）**
   - **処理対象**: 楽天（ヤフーは150バイトだが作業無し、ジェットプライスも作業無し）
   - **ルール**: キーワードの定義は「半角の空白」ごとに区切られている。
   - **処理**: サイトの文字数（楽天は255バイト）に引っかからないようになるまで、商品名（**「足し算」列 / U列**）から一番後ろの半角スペースを探し、キーワードのブロックごと削除する。（※万が一スペースがない単体の文字列でオーバーしている場合は、フェイルセーフとして1文字ずつ削除する）

## 4. 最終フォーマット調整 (normal item用)
サイト上にアップする形に整えるツール（既存の佐々木exeツール等）にかけるためのExcel形式（normal item）に整える作業。

* **データのズレ防止**: 「注文番号」と「商品名」の項目が元データから絶対にずれないように注意する（※Excel作業時特有の行ズレ警戒）。
* **商品管理番号**: `注文番号` を転記する。その際、`LOWER` 関数を使用してアルファベットを**小文字に変換**し、全体を**降順**に並び替える。
* **商品名**: 最終的にキーワード付与と文字数調整が完了した **「足し算」列（U列）** の値を転記する。
* **採番**: 上から 1, 2, 3... と数字を連番で割り当てる（元の手作業ではプルダウンで割り当て）。
* **ファイル分割出力**: 抽出・作成された各イベントのデータごとに、別々のExcelファイルとしてそれぞれ出力する。ファイル名は `normal-item_rc[イベント名].xlsx` とする。（例：normal-item_rcうんちょ.xlsx）
