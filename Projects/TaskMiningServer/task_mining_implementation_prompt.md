# タスクマイニングツール拡張 実装依頼プロンプト

## 背景・目的
社内SEとして、内製タスクマイニングツールを開発中（社内推進の許可済み）。
現状は以下のデータを取得し、部門単位・個人単位でレポート／ダッシュボード化している。

- キー入力具合（手入力かどうか）
- コピペ回数
- アクティブなファイル名
- アイドリング時間

このツールを拡張し、**業務フロー改善のきっかけ発見**と、**Python / Excel VBA / GAS / PowerShell による自動化候補の抽出**ができるようにしたい。
私（利用者）はPython・VSCode環境の開発初心者。段階的に理解しながら進められる実装にしてほしい。

## 開発環境・制約
- 言語: Python（メイン）。データ収集はPowerShellスクリプトを想定
- エディタ: VSCode
- データ保存先: CSV（将来的にNAS共有パスへ出力、Pythonで集計・グラフ化）
- 対象: Windows端末（SKYSEA Client Viewでの端末管理対象機）
- 初心者向けに、コードには日本語コメントを入れてほしい
- ライブラリは極力标準的なもの（pandas, matplotlib等）を優先し、大掛かりな依存は避けてほしい

## 実装してほしいこと

### 1. データ収集項目の拡張
既存項目に加えて、以下を新たに取得できるようにしたい。
- アクティブウィンドウのタイトル・プロセス名（現行の「ファイル名」を拡張）
- ウィンドウ切り替え（フォーカス変更）回数とタイムスタンプ
- コピー元アプリ／ペースト先アプリのペア記録
- 同一操作パターンの繰り返し検出（定型作業の検出用）
- 会議アプリ（Teams/Zoom等）のフォアグラウンド時間
- 部門コード・業務カテゴリのタグ付け（設定ファイルまたは簡易入力で紐付け）

収集スクリプトはPowerShellで、既存の収集ロジック（キー入力・コピペ・アイドル検知）に統合する形で拡張してほしい。出力はCSV1行＝1イベント、またはセッション単位のいずれかで、後段のPython集計がしやすい形式を提案してほしい。

### 2. 指標計算ロジック（Python）
CSVを読み込み、以下の指標を計算するPythonスクリプトを作成してほしい。

| 指標 | 計算式 |
|---|---|
| コピペ率 | コピペ文字数 ÷（手入力＋コピペ文字数） |
| 1時間あたりキー入力数 | 総キー入力数 ÷ 稼働時間 |
| アイドル率 | アイドル時間 ÷ 総稼働時間 |
| 平均アイドル継続時間 | アイドル時間合計 ÷ アイドル発生回数 |
| アプリ切替頻度 | 切替回数 ÷ 稼働時間 |
| 定型操作率 | 同一パターン検出回数 ÷ 総操作回数 |
| ファイル別作業時間 | ファイルごとの滞在時間合計 |
| 生産性偏差 | 個人指標 ÷ 部門平均 |
| 時間帯別負荷 | 30分〜1時間刻みでの各指標推移 |
| 自動化優先度スコア | 定型操作率 × 作業頻度（回/日） × 平均作業時間 |

- 部門単位・個人単位でそれぞれ集計できる関数構成にしてほしい
- 日次・週次で集計できるようにしてほしい
- pandasのDataFrameを中心に、関数は用途ごとに分割し、テストしやすい構成にしてほしい

### 3. 可視化（ダッシュボード／レポート）
以下のグラフを生成できるようにしてほしい。
- ヒートマップ：曜日×時間帯でのアイドル率／入力密度
- 積み上げ棒グラフ：1日の稼働時間を「入力」「アイドル」「切替ロス」「会議」で色分け
- 散布図：コピペ率×作業時間（自動化優先度の象限分け）
- ランキング表：ファイル／アプリ別の合計滞在時間 Top10
- レーダーチャート：個人 vs 部門平均の指標比較

matplotlib（＋必要ならseaborn）でPNG出力する構成と、可能であれば簡易Webダッシュボード（例: streamlit）化する構成の両方を提案し、どちらが自分（初心者）にとって着手しやすいかコメントしてほしい。

### 4. 自動化候補の出力
自動化優先度スコアが高い作業を一覧化し、以下の技術振り分けルールに従って推奨技術をタグ付けするロジックを実装してほしい。
- Excel内完結の定型転記 → Excel VBA
- Googleフォーム/スプレッドシート連携 → GAS
- PC操作の自動化・ファイル整理・監視系 → PowerShell
- 複数システムを跨ぐ分析・レポート自動生成 → Python

出力はCSVまたはExcelで、上長への報告にそのまま使える形にしてほしい。
