# Excelデータずれチェックツール 概要仕様書

* **対象環境**: `c:\Users\フォーレスト026\MyProject\Excelデータずれチェックツール`

## 1. アプリ概要
手作業等により行の途中でマージミスや行ズレが発生してしまったExcelファイルに対して、「作業前の元ファイル」と「作業後のファイル」を比較・検証するためのツールです。
特定の複数列のデータを結合して「完全なユニークコード」を生成し、そのコードが新旧ファイルで一致しているか（新しいファイルに未知のコードが発生していないか）を高速にチェックします。

## 2. 実装内容
* **使用技術**: Python (tkinter, openpyxl, pandas)
* **対象列**: C列, D列, T列, AB列, AD列, AF列 の6列
* **処理ロジック**:
  1. ユーザーが指定したフォルダ内の2つのExcelファイル（.xlsx）を自動で読み込みます（更新日時が古い方を「作業前」、新しい方を「作業後」と判定）。
  2. 各行の対象列の値を `_` で結合し、ユニークコードを生成します。
  3. 作業前・作業後の両ファイルの「最も右側の新しい列（最終列）」に、生成したユニークコードを書き込んで保存します。
  4. 新ファイルのコード一覧から旧ファイルのコード一覧を引き算し、差分（新しいファイルでのみ発生したコード）を抽出します。
* **フェイルセーフ対応**: UIスレッドのフリーズを防ぐため、Excelの読み書き処理は別スレッド（`threading`）でバックグラウンド実行します。

## 3. 使用方法
1. 任意のフォルダに、比較したい2つのExcelファイル（作業前ファイルと作業後ファイル）を入れます。
2. 本スクリプト `excel_diff_checker.py` を実行します。
3. フォルダ選択ダイアログが表示されるので、手順1のフォルダを選択します。
4. 処理が開始され、自動で比較が行われます。
5. 処理完了後、同じフォルダ内に `判定結果_差分なし_[日時].txt` または `判定結果_差分あり_[日時].txt` が出力されます。差分ありの場合は、どの行に新しいコードが発生したかが記録されます。
