# OA端末 キッティング手順（UI導線順）

## 1. OSインストール・初期セットアップ（OOBE）
Windows 11のインストールおよび、インターネット接続を回避してローカルアカウントを作成する手順です。
*   **基本設定**：
    *   インストール先：ドライブ0 パーティション2
    *   言語・時刻と通貨：日本語
    *   キーボード：Microsoft IME / 日本語キーボード
*   **ネットワーク接続のバイパス（ローカルアカウント強制作成）**：
    1. 「ネットワークに接続しましょう」の画面で `Shift + F10` を押す。
    2. コマンドプロンプトに `OOBE\BYPASSNRO` と入力してEnter（自動再起動される）。
    3. 再起動後の同画面で再度 `Shift + F10`。
    4. `netsh interface show interface` でアダプター名（Wi-Fi等）を確認。
    5. `"netsh interface set interface "Wi-Fi" disable"` でWi-Fiを無効化。
    6. コマンドプロンプトを閉じ、左上の「←（戻る）」ボタンをクリック。
*   **アカウント作成**：
    *   管理者ローカルユーザー名：`SysAdmin` で作成。
    *   セキュリティの質問：
        *   ペットの名前：`Forestway`
        *   ニックネーム：`ココデカウ`
        *   生まれた場所：`上尾`

## 2. 「設定」アプリでの設定
スタートメニューの「歯車マーク（設定）」から順番に行う項目です。

*   **ネットワークとインターネット**
    *   **Wi-Fi**：一番最初にWi-Fi接続を設定する（NTP同期等のため）。
*   **システム**
    *   **ディスプレイ**：夜間モードをON（設定数値10）。
    *   **通知**：ニュース通知などをOFF。
    *   **電源とバッテリー**：
        *   電源接続時：スリープしない
        *   ノートPCの場合（バッテリー駆動時）：10分でスリープ、シャットダウン
    *   **ストレージ**：ストレージセンサーをOFF。
    *   **マルチタスク**：ウインドウスナップOFF、タイムラインOFF。
    *   **クリップボード**：クリップボードの履歴をOFF。
    *   **リモートデスクトップ**：ONに変更。
    *   **バージョン情報（PC名の変更）**：PC名を変更（例：`FWN-033` ※FMVはこの名で登録）。
*   **Bluetooth とデバイス**
    *   **マウス**：マウスポインターの速度を「20」に変更。スクロールの一度にスクロールする行数を「1」に変更。「ホバーしたときに非アクティブウインドウをスクロールする」をOFFに変更。
*   **個人用設定**
    *   **背景**：個人設定の背景は指定の画像に変更。
    *   **テーマ**：「デスクトップアイコンの設定」を開き、「コントロールパネル」「コンピューター」にチェックを入れて表示させる。
    *   **ロック画面**：ロック画面の状態は「なし」に変更。「サインイン画面にロック画面の背景画像を表示する」はOFFに変更。
        *   **スクリーンセーバー設定**：スクリーンセーバーは「リボン」で待ち時間「5分」に設定。
    *   **スタート**：
        *   「最近追加したアプリを追加する」をOFFに変更。
        *   「スタートで推奨されるファイル、エクスプローラーで最近使用したファイル、ジャンプリスト内の項目を表示する」をOFFに変更。
        *   「ヒント、ショートカット、新しいアプリなどのおすすめを表示します」をOFFに変更。
        *   「アカウントに関連する通知を表示」をOFFに変更。
    *   **タスクバー**：
        *   検索：検索アイコンのみに変更。
        *   タスクビュー：OFFに変更。
        *   ウィジェット：OFFに変更。
        *   再開（チャット）：OFFに変更。
*   **時刻と言語**
    *   **日付と時刻**：NTP（インターネット時刻）サーバーを `ntp.nict.jp` に変更。
*   **アプリ**
    *   **既定のアプリ**：後述のソフトインストール後、Webブラウザを「Google Chrome」に、音楽・動画を「MPC」に変更。
    *   **スタートアップ**：タスクマネージャを起動し、不必要なアプリのスタートアップを無効化。
*   **Windows Update**
    *   **詳細オプション（配信の最適化）**：「他のPCからのダウンロードを許可する（ピアツーピア配信）」を OFF に変更（ネットワーク帯域節約のため）。
*   **プライバシーとセキュリティ**
    *   **推奨事項 & オファー**：以下の項目をすべてOFFに変更。
        *   パーソナライズされたオファー
        *   Web サイトに自分の言語リストへのアクセスを許可する
        *   スタート メニューと検索結果を改善する
        *   [設定] で通知を表示する
        *   [設定] の推奨事項とオファー
        *   広告識別子

## 3. 「コントロールパネル」および管理機能での設定
デスクトップに出したコントロールパネル等から行う、少し深いシステム設定です。

*   **ユーザーアカウント（UAC設定）**：
    *   ユーザーアカウント制御設定を「通知しない（全OFF）」に変更。
*   **電源オプション**：
    *   電源ボタンを押したときの動作：「シャットダウン」に変更。
    *   スリープボタン / カバーを閉じたときの動作：「何もしない」に変更。
    *   **(※重要)** DELL等の「モダンスタンバイ (Modern Standby / S0)」対応機の場合、上記設定がGUIに存在しない、またはスクリプト(`powercfg`)から正常に適用されない場合があります。その場合は `Dell Optimizer` などのメーカー独自ツールやBIOS画面での設定変更を併用して対応してください。
*   **システムの詳細設定（`sysdm.cpl`）**：
    *   **パフォーマンス**：ウインドウの下に影をつける等の不必要なアニメーション・視覚効果をOFF。さらに以下をOFFにする。
        *   タスクバーでアニメーションを表示する
        *   プレビューを有効にする
        *   メニュー項目のクリック後にフェードアウトする
        *   **(レジストリ設定)** `MenuShowDelay` を `400` から `20` に変更（メニュー表示の高速化。※0にするとバグるため20とする）。
*   **BitLocker ドライブ暗号化**：
    *   保護の中断（OFFにする作業）。
*   **コンピューターの管理（`compmgmt.msc`）**：
    *   **ローカルユーザーとグループ**：`SysAdmin` 等のユーザーのプロパティから「パスワードを無期限にする」にチェック。
*   **サービス（`services.msc`）**：
    *   `Windows Search`：無効化（インデックス作成オフ）。
    *   `Internet Connection Sharing (ICS)`：停止。
    *   `SysMain` (旧 SuperFetch)：無効化（裏でのディスク・メモリ消費を抑え、動作を軽量化するため）。
*   **ドライブのデフラグと最適化**：
    *   ローカルディスク最適化を実行（一番下のチェックを外す。エラーは無視）。

## 4. コマンドプロンプト・レジストリ等で行う特殊設定
*   **UACの完全無効化（レジストリ）**：
    *   管理者コマンドプロンプトで実行：`reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v EnableLUA /t REG_DWORD /d 0 /f`（実行後再起動が必要）
*   **ハイバネーション（休止状態）の無効化**：
    *   管理者コマンドプロンプトで実行：`powercfg.exe /hibernate off`
*   **ネットワークドライブ割り当て**：
    *   NAS（`Y:`）：`\\frt-nas` ※川口物流等は `\\10.85.33.230` （ユーザー：`frt_user` / パス：`Forest0720@`）
    *   （※旧共有サーバー X: は現在使用しないため展開不要）
*   ※補足：必要に応じてビルトインAdministratorを有効化（`net user administrator /active:yes`）して作業し、完了後に無効化する。

## 5. ソフトウェアのインストール・ブラウザ設定
端末の種類（OA端末か仮想基幹端末か）によってインストールするソフトウェアを分岐させます。

*   **端末の分岐によるインストール**：
    *   **OA端末の場合**：Office365 → 7-Zip → Acrobat Reader → Chrome → ESET(OA用) → SKY(OA用)
    *   **仮想基幹端末の場合**：Office2010 → 7-Zip → Acrobat Reader → Chrome → VM-Ware → ESET(基幹用) → SKY(基幹用)
    ※いずれの場合もUSBメモリがブロックされるのを防ぐため、SKYのインストールは一番最後に行う。

*   **ブラウザ（Edge）（インストール済み）**：
    *   PDFをEdgeで開かせない設定。
    *   エクスペリエンス調整OFF、SmartScreen OFF。
*   **ブラウザ（Chrome）（自動インストール希望）**：
    *   インストール後、サイドバーOFF、Office365 OFF、Discoverタブ調整OFF、スマートアクション無効など。
    *   外観OFF、IEモードを有効に変更。履歴削除。
*   **メディア・周辺機器**：
    *   **プリンタドライバ**：ドライバ格納フォルダから自動インストールを実施（自動化希望）。
    *   （実施しない）MPC（Media Player Classic）インストール。
*   **セキュリティ・管理ソフト**：
    *   **ESET インストール**：シリアルキーを使用してアクティベーションを行う。
    *   **Sky インストール**：フォルダ内のexeファイルから自動インストール（自動化希望）。Sky用のポート設定HTMLファイルもインストール。

## 6. 自動キッティングおよび運用時の重要事項

PCキッティングを行う際、特に「ユーザーの切り替え」においてWindowsの仕様上、以下の点に注意が必要です。

### ユーザープロファイルと設定の引き継ぎについて
Windowsの各種設定やアプリには、「**PC全体（全ユーザー共通）の設定**」と「**ユーザー固有の設定**」の2種類が存在します。初期セットアップ用のアカウント（例：`Administrator`）で設定や自動スクリプトを実行した後、新しく作成したユーザー（例：`SysAdmin`）でログインし直すと、設定の一部が初期状態に戻る（反映されていないように見える）現象が発生します。

*   **引き継がれるもの（PC全体の設定 / レジストリ: HKLM）**
    *   インストールされたアプリケーション（Office, Chrome, ESET, SKYなど）
    *   ネットワーク設定（固定IPアドレス、Wi-Fiの接続プロファイル）
    *   UAC（ユーザーアカウント制御）の無効化
    *   電源オプションやBitLockerの設定
*   **リセット（初期化）されるもの（ユーザー固有の設定 / レジストリ: HKCU）**
    *   マウスの速度やスクロール設定
    *   画面の視覚効果（パフォーマンス優先、アニメーションOFFなど）
    *   タスクバーやスタートメニューの配置・アイコン設定
    *   壁紙（背景画像）やエクスプローラーの表示設定
    *   NAS（Yドライブ）などのネットワークドライブ割り当て

**【運用上の対策】**
キッティングの際、マウスや画面の視覚効果、タスクバー等の「ユーザー固有の設定」を確実に反映させるためには、**実際にそのPCを利用する最終的なユーザー（例：`SysAdmin` 等）でログインした状態から、自動化スクリプトを実行する（または手動設定を行う）**必要があります。別のアカウントで実行した内容は引き継がれないためご注意ください。

### メーカー（機種別）の自動判定と専用チューニングについて
現在のキッティングスクリプト（`Set-CorporateStandardEnvironment.ps1`）には、実行されたPCのメーカー（FUJITSU や Dell など）を自動判定する仕組みが組み込まれています。
これにより、**「DELLのPC（Latitude等）なら高精度タッチパッドの設定や、マウス速度の専用設定を流し込む」「富士通のPCなら富士通用の設定を流し込む」**といった処理が全自動で行われます。
新しい機種が導入された場合は、『PCメーカー別_自動設定化プロジェクト計画書』の手順に沿って変更前後のレジストリ差分を取得し、スクリプトの判定ロジック内に新機種用のチューニングコードを追加していく運用となります。
