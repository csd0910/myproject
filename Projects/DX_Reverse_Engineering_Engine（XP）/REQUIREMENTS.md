# DX_Reverse_Engineering_Engine (Windows XP版) 要件・仕様書

## 1. システム概要
本システムは、Windows XP環境で動作する「軽量・低負荷なタスクマイニング用データコレクター」です。
インターネットに接続されていない（またはセキュアな）XP端末上でのユーザー操作履歴を記録し、後続のAI解析エンジン（`DX_Reverse_Engineering_Engine`本番機）へ渡すためのCSVファイルを生成します。

**設計思想:**
*   XP端末のCPU・メモリリソースを極力消費しない。
*   AI解析や重いファイル処理（Excel内容の直接解析やPowerPoint生成など）は一切行わず、純粋なテレメトリデータの出力に徹する。

---

## 2. システム構成・アーキテクチャ

1.  **クライアント側（本アプリケーション / Windows XP）**
    *   ユーザーのPC操作状況（アクティブな画面、キー入力頻度、コピーしたテキストなど）を一定周期で監視。
    *   監視結果をローカルのCSVファイルに時系列で書き出す。
2.  **サーバー側（現行のDX_Reverse_Engineering_Engine / インターネット接続PC）**
    *   出力されたCSVファイルを読み込み、AI（Gemini等）を用いて業務の自動化ポイントやボトルネックを分析・可視化する。

---

## 3. 取得・出力するデータ項目（CSVフォーマット）

出力されるCSVは、解析側エンジンと互換性を持たせるため、以下のカラム（列）を持ちます。

1.  **開始日時**: ウィンドウや状態が切り替わった開始時間（例: `YYYY/MM/DD HH:MM:SS`）
2.  **終了日時**: 状態が終了した時間
3.  **滞在時間**: その画面や作業に留まっていた時間（秒）
4.  **状態**: `作業中` または `離席中` （一定時間操作がない場合は離席と判定）
5.  **アプリケーション名**: 実行ファイル名（例: `EXCEL.EXE`）
6.  **ウィンドウタイトル**: 開いているファイル名や画面名（例: `週次報告書.xlsx - Excel`）※ダイアログボックスなど子ウィンドウの変化も検知して記録する
7.  **打鍵数 / マウスクリック数**: その作業期間内にキーボードを叩いた回数、マウスをクリックした回数（作業の重さの指標）
8.  **クリップボード転記内容・形式**: コピーされたテキストの先頭数十文字。画像やファイルの場合は `[画像データ]` `[ファイル]` 等と形式を記録し、作業内容を推測可能にする

---

## 4. 実行環境・想定技術スタック

*   **対象OS:** Windows XP (SP3想定)
*   **開発言語案:**
    *   C# (.NET Framework 2.0 または 4.0): 開発効率が良く、GUIやCSV出力の実装が容易。
    *   C++ (Win32 API): .NETも不要な究極の軽量化を目指す場合。
*   **使用する主要API (Windows API):**
    *   `GetForegroundWindow`, `GetWindowText`, `GetWindowThreadProcessId` (ウィンドウ情報取得)
    *   `SetWindowsHookEx` (WH_KEYBOARD_LL, WH_MOUSE_LL) または `GetLastInputInfo` (入力監視・離席判定)
    *   `GetClipboardData` (クリップボード取得)

---

## 5. 使用方法（想定）

1.  XP端末に本アプリケーション（実行ファイル `.exe`）を配置。
2.  アプリを起動すると、タスクトレイまたは小さな画面に常駐し、記録を開始する。
3.  業務終了時、出力されたCSVフォルダから当日のCSVファイルをUSBメモリ等で回収する。
4.  インターネット側のPCにて、現行の `DX_Reverse_Engineering_Engine` にCSVを読み込ませる。
