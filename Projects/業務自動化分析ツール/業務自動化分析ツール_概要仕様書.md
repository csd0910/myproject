# 業務自動化分析ツール 概要および仕様書

## 1. 概要
本ツールは、ユーザーのPC操作（キーボード入力、Excel操作、アプリ使用状況、クリップボードなど）をバックグラウンドで監視・記録し、その生ログを基にAI（Gemini 2.5 Flash）を利用して日報や詳細なDX提案レポート（HTML形式）を自動生成するシステムです。
操作の記録から「手作業のコスト」や「コピペの反復」を浮き彫りにし、業務コンサルタント視点での具体的な自動化（PythonやVBA）の要件定義を強力に支援します。

## 2. 使用方法
1. `gui_app.py` を実行すると「DX推進アシスタント」のGUI画面が起動します。
2. ログの保存先フォルダ（デフォルト：`C:\AutoAnalysisLogs`）を指定し、「記録開始」ボタンを押下します。
3. 業務終了時に「記録停止」ボタンを押し、その後「日報（MD/HTML）を出力する」ボタンをクリックします。
4. 指定したフォルダに分析済みのレポート（HTML形式やCSV形式）が生成されます。

## 3. 機能とプログラムの特徴
* **非同期・軽量ロギング (`system_logger.py`)**: 
  PCの動作を重くしないよう、インメモリのキューと専用スレッド（非同期処理）を活用しています。特にExcelの監視では `win32com` を用いて、イベント（セル変更等）を10ms間隔で専用スレッドから傍受しラグを排除しています。
* **物理キーロガーとクリップボード監視**: 
  `pynput` による打鍵監視で「Ctrl+C」「Ctrl+V」などの制御文字を検出し、`pyperclip` でクリップボードデータのテキスト（コピー元アプリ等）を関連付けて記録します。
* **AIによる自動解析とレポート生成 (`generate_daily_report.py`)**: 
  記録したCSV生ログをGemini APIに送信し、意味のある操作として集約・解釈します。結果は、Chart.jsを用いた円グラフや、Mermaid記法による業務フロー図を含む綺麗なHTMLとして出力されます。
* **図解レポートの生成 (`generate_visual_excel_report.py` 等)**: 
  AIの解析結果を基に、どこを操作したのかを視覚的にバルーンで指し示すExcelレポートも生成可能です。

## 4. APIの内部プロンプト
`generate_daily_report.py` に組み込まれているGemini API向けの主なプロンプト内容です。

### ① 簡易モード（日報）プロンプト
* **目的**: 1日の業務をまとめた綺麗なHTML日報を作成。
* **指示内容**: タイムラインログと詳細操作ログを統合し、「本日の主な業務サマリ」と「タイムライン」を生成する。その際、どのような関数（VLOOKUP等）を組んでいたか、どんな手作業・コピペをしていたかの具体例をサマリに盛り込む。

### ② 詳細DX抽出モードプロンプト
* **目的**: システム部が自動化の仕様書を定義できるレベルの詳細な分析と提案。
* **指示内容**: 
  * エグゼクティブ向けの業務コンサルタントとして振る舞うこと。
  * 操作した主要ファイルと「手作業の実時間」「自動化した場合の想定削減時間」を算出する。
  * 「現在の処理フロー図」と「自動化後のフロー図」をMermaid記法で出力する。
  * **制約事項**: RPA（UiPathやWinActorなど）は絶対に使用・提案せず、最優先で「Python」、次点で「Excel VBA」による自動化スクリプトの開発を提案すること。

### ③ 生ログへのAI要約付与（CSV出力）プロンプト
* **目的**: ユーザーの操作生ログに、人間が読んで理解できる「AI解析要約」列を追加する。
* **指示内容**: 
  * 「何を」「どう入力したか」を具体的に記述する。（例：「セルC8に『=VLOOKUP(...)』という数式を手入力している」）
  * **連続操作の集約**: 縦方向のドラッグコピーなど反復作業とみなせるログは1行に圧縮し、対象セル範囲（例: Cell:A9:A15）を残す。
  * **キー操作の強烈なアピール**: 「Ctrl+C」「Ctrl+V」を用いたコピペ操作が行われたことを、自動化要件定義のために強烈にアピールして記述する。
