# 作業課題記録ツール (佐々嶌仕様)

## 📌 概要
日々の課題や対応履歴をカンタンに入力し、CSV形式で任意の場所に記録・蓄積できる専用ツールです。

## ✨ 主な特徴
- **タスクトレイ常駐型**
  ウィンドウの「✕」ボタンを押してもアプリは終了せず、バックグラウンド（画面右下のタスクトレイ）で待機し続けます。他の作業の邪魔になりません。
- **瞬間呼び出し（ホットキー）**
  待機中でも `Ctrl + Shift + W` キーを押すだけで、一瞬で手前にウィンドウが現れます。入力後、再度ホットキーを押すか、保存（`Ctrl + Enter`）するとサッと隠れます。
- **組織図に基づいた入力支援**
  組織図のマスタデータを搭載しており、「部」を選ぶと連動して「課」のプルダウンが切り替わります。（もちろん、新しい部署を自由に手入力することも可能です）
- **キーボードだけでサクサク入力**
  テキスト入力中も `Tab` キーで次の項目へ移動できるため、マウスを使わずにスムーズに記録が完了します。

## 🚀 使い方
1. 同梱されている `Workmemo_Sasajima.exe` をダブルクリックして起動します。
2. 初回起動時、ウィンドウ右上の **「📁保存先CSV変更」** ボタンを押し、記録を保存したい場所（共有フォルダやデスクトップなど）にファイルを作成・指定します。
   （※一度指定すれば、次回からは自動でそのファイルに追記されます）
3. 「依頼部署」「課題内容」などを入力します。（日付や年度は最初から本日のものが入力されています）
4. キーボードの **`Ctrl + Enter`** （または右下の保存ボタン）を押すと、CSVにデータが保存され、ウィンドウが自動で隠れます。

## ⚙️ 設定の変更
- **PC起動時の自動起動（スタートアップ登録）**
  ウィンドウ左上の「⚙」ボタンを押し、設定画面から「登録」ボタンを押すことで、Windowsの起動時に自動的に本ツールが立ち上がり、タスクトレイに常駐するようになります。PCを開いてすぐにホットキーで記録を始めたい場合に便利です。
- **担当者名の変更** や **ホットキーの変更（例: `Alt + Q` など）** は、ウィンドウ左上の「⚙」ボタンから行えます。
- 部署・課のマスタを更新したい場合は、自動生成される `data/config_sasajima.json` ファイルをメモ帳等で直接編集してください。

## 🛑 終了方法
画面の「✕」ボタンを押しただけでは完全に終了しません。
完全に終了させたい場合は、画面右下（時計の横）にあるアイコン一覧から、本ツールのアイコン（青と白の四角形）を **右クリック** し、**「終了」** を選択してください。

---
*別のPCで利用する場合も、この `Workmemo_Sasajima.exe` をコピーするだけでそのまま動作します（Pythonのインストール等は不要です）。*
