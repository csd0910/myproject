# Workmemo Unified - 業務記録統合ツール

「他部署受付」「ヘルプデスク」「保守」の3つの記録業務を1つに集約し、過去のデータを賢く再利用・更新するためのツールです。

---

## 🚩 導入の進め方（最初に行ってください）

アプリを起動したら、まずは以下の設定を行ってください。

1.  **設定の変更**:
    *   画面左上の **「⚙ 設定」** ボタンを押します。
    *   **担当者名** を入力します。
    *   **保存先Excel**: 「変更」ボタンを押し、自分が管理したい場所に新しいExcelファイルを作成するか、既存のファイルを選択します。
    *   **ホットキー**: 使い慣れたキー（標準は `Ctrl+Shift+W`）に設定します。
2.  **過去データの移行（履歴機能をフル活用するために）**:
    *   現在スプレッドシートや別のExcelで管理している過去のデータを、上記で指定したExcelファイルの各シート（「他部署受付」「ヘルプデスク」「保守」）にコピー＆ペーストしてください。
    *   **重要**: 佐々嶌氏が運用しているスプレッドシートへ転記ができるようにしてあります。逆にスプレッドシートから記録をコピーし、ヘッダー（1行目）の項目名に合わせてデータを貼り付けることで、アプリの **「👔 履歴から選択」から過去の仕事をすべて呼び出せるようになります。**

---

## ✨ 便利な機能と活用フロー

### 1. 過去の記録を「再利用」する
「以前やったあの作業とほぼ同じ」という時は、履歴から呼び出すのが一番早いです。
- 履歴画面で対象をダブルクリック ＞ 内容が自動入力される ＞ 必要箇所だけ直して **「新規保存」**。
- これで、過去のテンプレートを活かして素早く新しい記録が作れます。

### 2. 未完了案件を「更新・完了」させる
「一旦保存したけれど、まだ終わっていない仕事」の管理に最適です。
- 履歴画面で **赤く表示されている行（未完了・進行中）** を探します（フィルタで絞り込むと便利です）。
- ダブルクリックで呼び出し ＞ 進捗やステータスを「完了」に書き換え ＞ **「上書き修正」** をクリック。
- これで、Excelの元の行が直接更新され、案件がクローズされます。

### 3. 保存後も閉じない画面
- 保存ボタンを押しても画面は消えません。連続して複数の案件を記録する際も、いちいち呼び出し直す必要がなくスムーズです。

## ⌨️ 操作コマンド
- **表示/非表示**: `Ctrl + Shift + W` （設定で変更可能）
- **保存**: `新規保存` ボタン または `Ctrl + Enter`
- **修正**: `上書き修正` ボタン（履歴から呼び出した時のみ有効）

## 📂 データ構成
- **設定ファイル**: `data/config_unified.json`
- **Excelデータ**: 指定したパスのExcelファイル。シート名は「他部署受付」「ヘルプデスク」「保守」となります。
