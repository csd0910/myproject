# Windowsキッティング自動化ツール マニュアル

## 1. 概要
本ツールは、Windows端末の初期セットアップ（キッティング）を自動化・半自動化するためのPowerShellスクリプトパッケージです。
OS設定、ネットワーク設定、アプリケーション導入、システム最適化を一括で実行します。

## 2. 主要機能
- **対話型GUI**: PC名やユーザー名をマウス操作で入力可能。
- **基盤設定**: 管理者(SysAdmin)の作成、UAC無効化、デスクトップアイコン表示。
- **ネットワーク**: 固定IP設定、NAS資格情報の保存、ネットワークドライブ(Y:)の割り当て。
- **アプリ自動導入**: 
  - Chrome, 7-Zip, Office 365 ODT の自動ダウンロードとインストール。
  - NAS上のインストーラー（Sky, ESET, Adobe Reader等）の自動実行。
  - 不要なLhaplusの自動削除。
- **OS最適化**: 不要サービスの停止、視覚効果の高速化、おすすめ情報の非表示。
- **堅牢な設計**: ネットワークエラー時の自動リトライ（最大3回）、詳細ログの出力。

## 3. フォルダ構成
- `Start-Kitting.ps1`: メイン実行スクリプト（これを実行します）。
- `Config.ps1`: NASパスやアプリ名、ログ保存先の定義ファイル。
- `Lib/`: ログ出力やGUIフォームなどの共通プログラム。
- `Modules/`: 各工程（設定、通信、アプリ、最適化）の実行プログラム。
- `Rollback/`: 設定を元に戻すためのスクリプト。

## 4. 準備（事前設定）
実行前に `Config.ps1` と `Modules\02_NetworkStorage.ps1` を開き、以下の項目を確認・修正してください。

1. **NASパス**: `Config.ps1` の `$Config.NASPath` を環境に合わせて修正。
2. **NAS認証情報**: `Modules\02_NetworkStorage.ps1` 内の `$NasUser` と `$NasPass` を実際のID/PASSに変更。
3. **インストーラー名**: `Config.ps1` の `LocalApps` に、NAS内に置いたファイル名を正しく記載。

## 5. 操作手順
### 手順1：実行
`Start-Kitting.ps1` を右クリックし、**「管理者として実行」**を選択します。

### 手順2：入力
表示されたGUIフォームに以下の情報を入力して「開始」を押します。
- **コンピューター名**: 変更が必要な場合に入力。
- **ユーザー名**: 作成したいローカルユーザー名を入力。
- **固定IPを設定する**: チェックを入れると指定のIPが設定されます。

### 手順3：待機
コンソール画面（黒い画面）に進行状況が表示されます。
- 緑色：成功
- 黄色：リトライ中/警告
- 赤色：エラー

### 手順4：完了
全ての工程が終わると、メッセージボックスが表示されます。「はい」を押すと自動的に再起動し、設定が反映されます。

## 6. ログとトラブルシューティング
実行結果は `C:\Kitting_Log.txt` に保存されます。
エラーが発生した場合は、このログを確認し、エラーメッセージに基づいて `Config.ps1` 等の設定を見直してください。

## 7. 設定の復元（ロールバック）
設定を元に戻したい場合は、`Rollback\Restore-Settings.ps1` を管理者として実行してください。UACの有効化やレジストリの一部を初期状態に近づけます。
