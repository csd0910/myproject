# 配送用スマートフォン機種変更に伴う状況および課題報告書

**作成日:** 2026年8月24日
**宛先:** 上長各位
**件名:** 8/22(土)～8/23(日) 配送用スマートフォン（48台）機種変更作業における問題点と今後の対応について

## 1. 概要
8月22日(土)および23日(日)にかけて実施した、物流配送用スマートフォン48台の機種変更および初期設定作業についてご報告いたします。
事前の基本設定（MDMインストール等）は2.5営業日で完了していましたが、当日の現地作業において配送部門側の連携・準備不足、および作業分担の不明確さにより、
当初22日に完了予定であった作業に大幅な遅延が生じ、23日の休日追加出勤を余儀なくされる事態となりました。

以下に、発生した問題点および今後の改善要望を報告いたします。

## 2. 発生した主な問題点

### ① 配送部門の連携・事前準備不足による大幅な作業遅延
*   **端末移送の手配漏れ:** 新旧端末を揃えての切替作業が必要である旨を事前に依頼していたにもかかわらず、配送側（高橋課長）の手配・連絡の不備により、新砂倉庫にある
約20台が予定通り21日(金)夜間に東日本物流へ移送されていませんでした。

*   **リカバリーによる手待ちとタイムロス:** 担当社員の自走回収等により14:30に新砂分が到着するまで全台一括処理ができず作業の分断が発生しました。また、個人の私物（ストラップ等）が
外されていない状態での持ち込みもあり、不要な取り外し・移植作業も依頼されその分手間も発生しました。

*   **充電環境の未整備と意思決定の遅延:** 翌月曜朝の業務に向けて「満充電で渡したい」との現場要望がありましたが、川口・新砂ともに全台数を同時に充電できる環境が未整備でした。
また、現場状況をシステム側で把握できない中、高橋課長からの作業優先順位の指示・判断が遅れ、作業手順の再構築に時間を要しました。
（当初の夜間便での発送予定から、担当者不在を理由に川口での充電＋月曜朝の持ち込みへ変更され、最終的に日曜日の持ち込みになるなど、予定の変更が二転三転し、それに伴う作業順の変更が多発しました）

### ② システム部門と配送部門の作業分界点の曖昧さ（業務の丸投げ）
*   **本来のシステム管轄外作業の負担:** システム部門の本来の作業領域は「MDM（SMSM）設定、台帳登録、Googleアカウント設定、配送支援アプリのインストール」までです。
しかし、**保護フィルム貼付、保護ケース装着、管理番号シール貼付**といった、本来ユーザー（配送側）が行うべき物理的な作業までシステム部に依頼され、この付帯作業で時間を空費する結果となりました。
他社員も運用中でしたので補助は頼みませんでした。

### ③ Googleアカウント移行および回線切替（eSIM）の技術的ボトルネック
*   **回線切替と認証の仕様:** eSIMへの回線切替後、新端末でGoogleアカウント（配送支援アプリ導入に必須）にサインインしようとすると、旧端末に2要素認証が飛ぶ仕様となっています。
端末により内容の違いが出て、サインインできない、復元作業が必要となるなど同一の作業にできず個別での操作が必要で時間がかかります。
*   **通信環境の限界:** 新旧両端末での操作が必要となり、さらにWi-Fiルーターの接続台数制限なども重なり、2要素認証にも1台あたりの情報入力と認証突破に多大な時間を要しました。
今回のように一度に大量の処理を行う場合、休日を利用しないと一括処理が困難な状況です。

## 3. 今後の改善・要望事項（総括）

今回の事象を踏まえ、今後同様の機器リプレースを行う際は、現場の負担軽減とスムーズな導入のため、以下のルール化を強く要望いたします。

1.  **作業分界点の厳格化:** 保護フィルム貼付やケース装着、シール貼りなどの物理的セットアップは、システム部門では一切お受けせず、配送部門側で実施いただくことを徹底したいと考えております。
2.  **事前準備・環境構築の徹底:** 端末の確実な事前移動、十分な充電環境の用意など、作業を円滑に進めるための最低限の現場準備を配送部門側の責任で行っていただく必要があります。
3.  **計画的なスケジュール策定:** 今回のような大量台数（48台）のeSIM切替およびアカウント移行を1日で完了させるのは、作業工程上非常に困難です。現場の連携ミスや意思決定の遅れが直ちに致命的な遅延に繋がるため、
余裕を持った段階的な移行スケジュールの立案と、それに伴う配送部門側の協力が不可欠です。

また、1度の作業で全対象端末を一括で切り替えることは運用上困難です。au (KDDI) の規定により、端末購入の当月内に回線切り替えを完了させる必要があるため、今後は対象月を分けて台数を分散させる必要があります。
具体的には48台の機種変更を2か月に分けるなどしてさらに「1日あたり最大10台×5日」程度に分割しないと、平日稼働との兼ね合いで各事業所での端末回収・設定・配布の調整が破綻します。

また、使用状況の把握、端末の回収・配布の調整、運用に必要な備品・アクセサリの手配・設定は運用する部門にて行っていただきたいと考えております。
