===========================================================
サイボウズOffice Eメール抽出＆AI自動整形ツール
(cybozu_external_email_exporter.exe)
===========================================================

【1. 作成の目的】
サイボウズOfficeの「Eメール」機能から、社外および社内とのやり取りを全自動で抽出し、手元にファイルとして永久保管するためのツールです。
さらに本ツールは抽出と同時に「AI向けの見やすい構造」へと自動変換・整形する機能も搭載しています。生成されるデータを NotebookLM などのAIツールに読み込ませることで、「長文のやり取りの要約」や「過去の議論の検索」を圧倒的な高精度で行うためのアシスト機能となります。

【2. 使用方法】
① 配布された「cybozu_external_email_exporter.exe」をダブルクリックして起動します。
② 画面上部の「保存先フォルダ」を任意で作成・指定します。
③ ログインURLを確認し、[ブラウザ起動]を押します。
④ 起動したEdgeブラウザ上でご自身のアカウントでログインし、左のツリーから「抽出したい対象のEメールフォルダ」を開きます。
⑤ 当アプリの[Eメール抽出開始]ボタンをクリックすると、自動操作で次々と抽出が進みます。必要な分だけ抜き出したい場合は、途中で[中断・停止]ボタンを押すことで処理を安全に終了できます。

【3. 出力されるデータの形式と「MDファイル」を分けた理由】
抽出を実行すると、指定したエリアに
「〇〇フォルダ_個別(オリジナル)」
「〇〇フォルダ_個別_MD」
の２つのフォルダが自動生成され、同時に2種類のファイルが抽出されます。あえて保存形式を分けているのには明確な理由があります。

◆ txt形式（オリジナルフォルダ内）
　取得した生のテキスト情報を破壊することなくそのまま保存した、証跡保管用のバックアップファイルです。Eメールの一覧画面と全く同じ構成になるよう「1通につき1ファイル」独立して保存されます。

◆ md（Markdown）形式（MDフォルダ内）
　本ツール最大の目玉であり、AI（NotebookLMなど）に読み込ませた際に「人間も機械も圧倒的に見やすくなる」よう、自動で中身を大工事した完成品データです。
　「全員に返信」等のEメールに付随する不要なシステムノイズを消し去っています（※添付ファイル名など、のちの検索でヒントになる情報はあえて残しています）。
　これにより、NotebookLM上にこの形式のファイルを放り込むだけで見栄えが格段に良くなり、AIの分析精度が飛躍的に向上します。

（※なお、フォルダ内で名前順ソートが綺麗に機能するよう、各ファイル名は元の件名・Re等を維持したまま「20260406(月)_0938_宛先(または送信者)_件名」の形式で自動的にキレイに「0埋め」されて作成されます）

【4. 技術的な内容・工夫点】
● プログラム構成と環境
  言語: Python 3 / GUI: Tkinter / 自動化ツール: Selenium WebDriver
  実行ファイルの生成: PyInstaller（Edgeブラウザを裏側で操作するための専用環境を内包しています）

● 実務ベースの機能調整と高速化
  差分抽出アルゴリズムを搭載しているため、一度処理したファイルはURL等の複合キーで記憶し、次回以降スキップして超限界スピード（0.1〜0.3秒）で新規メールのみを取得します。また、Eメール一覧画面特有の「次の50件 / 前の50件」のページネーションの複雑な入れ替わりにも完全対応しています。

● 高度な正規表現（Regex）からの精密操作
ユーザーの実際の画面XPathと高度な正規表現を掛け合わせたことで、複雑な構造を持つEメールの内部テーブルから「宛先」「CC」「日時」「添付ファイルを含む本文」を百発百中で正確にキャッチして保存する堅牢な仕様になっています。Windowsのパス制限や禁止文字によるシステムエラーを自動回避する安全な設計です。
