===========================================================
サイボウズ専用テキスト → Markdown一括変換ツール
(cybozu_markdown_converter.exe)
===========================================================

【1. 作成の目的】
サイボウズOfficeから抽出した長大なメールやコメントのやり取り（テキストデータ）を、NotebookLMなどのAIツールへ読み込ませる前段階の処理として開発されました。
AIが「誰の発言か」「どこからどこまでが1つのコメントの区切りか」を正確に理解・分析できるよう、人間も機械も圧倒的に読みやすい「Markdown形式（.md）」へと全自動で構造化・成形します。

【2. 使用方法】
① 配布されたアプリケーション（cybozu_markdown_converter.exe）をダブルクリックして起動します。
② 「フォルダを参照...」ボタンをクリックし、抽出済みのテキストファイル（.txt）が入っている対象フォルダを選択します。
③ 「Markdown (.md) へ変換」のボタンをクリックします。
④ 変換が完了すると、選択したフォルダの中に『md変換済み』という新しいフォルダが自動作成され、そこに完成品が保存されます。
（※オリジナルである元のtxtファイルは破壊されずにそのまま保管されますのでご安心ください）

【3. 変換ルール・出力データの形式】
◆ フォーマットの変更
  ファイル名は元の名前をそのまま引き継ぎ、拡張子のみを「.md」へと変更し、BOMなしUTF-8のクリーンな形式で保存します。

◆ UIと直感的なブロック分割
  ・「【件名】〇〇」をMarkdownの一番大きな見出し「# 〇〇」へ変換。
  ・サイボウズのコメントブロックを自動で感知し、「## 💬 コメント 番号：氏名（日時）」という分かりやすいサブ見出しに昇格。
  ・発言ごとに、画面幅いっぱいに折り返される「圧倒的に長い全角の線（ーーーー...）」を仕切りとして挿入。どれだけ長文のやり取りが続いても、どこで人が入れ替わったか一発で分かるように境界を引きます。
  ・文章中のURLを自動でマークダウン形式のクリッカブルリンク（クリック可能な状態）に変換します。

◆ AIの誤認識を防ぐ「ノイズ除去」
  「確認しました」「返信する」「宛先をすべて表示する」「詳細 155 KB」「プレビュー」など、サイボウズのシステム特有のボタン文字や不要な添付容量テキストを完全消去。AIが要約したり回答を探したりする際に邪魔になる純粋なノイズを事前に一掃します。

【4. 技術的な内容・工夫点】
● プログラム構成と安全性
  言語: Python 3 / GUI: Tkinter / その他依存: 組み込み標準ライブラリのみ
  レジストリの変更や外部環境への依存・通信を一切行わない、完全に独立した安全なスタンドアロン・プログラムです。

● 行またぎの高度な正規表現（Regex）検索
　サイボウズ特有の「データが縦に複数行に散らばる現象（番号→改行→氏名→改行→日付というフォーマット）」に対して、行またぎでマッチングを行う「MULTILINE対応の正規表現」を実装。イレギュラーな空白や改行の乱れがあっても、正確に発言者のブロックを取り出して見出しに変換します。

● 安全なファイル隔離機構
　出力時、変換前と後のファイルが同じ場所でごちゃ混ぜにならないよう「md変換済みフォルダ」を自動作成するルーチンを搭載。また「抽出履歴ファイル」など、変換してはいけないシステム用のテキストを自動で弾く安全フィルターを備えています。
