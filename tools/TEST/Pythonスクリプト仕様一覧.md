### 1. BizStorage_Cybozu_Agent.py
**用途（何のためにあるか）**
Cybozuのメール送信画面から宛先などの情報を読み取り、Bizストレージを使った安全なファイル送信作業を自動化・簡略化するためのGUIツールです。

**機能（何をしているか）**
- 画面上のメール作成ウィンドウから、宛先メールアドレス、件名、パスワードなどを自動抽出（`pywinauto`を使用）。
- 抽出した情報を用いて、ブラウザ（Edge）を裏で自動操作し、Bizストレージへログイン、ファイルのアップロード、宛先への送信までを自動実行（`Selenium`を使用）します。
- タスクトレイに常駐する機能もあります。

**使い方（どう使うか）**
1. スクリプトを実行してアプリを起動します。
2. 送信したい添付ファイルを選択します。
3. ご自身のブラウザでCybozuのメール送信画面を手前に開いた状態で、「1. 開いているブラウザから抽出」ボタンを押します。
4. 宛先などがアプリに読み込まれたことを確認し、「2. Bizストレージ送信」ボタンを押すと自動送信が始まります。

### 2. BizStorage_Delay_Monitor.py
**用途（何のためにあるか）**
Bizストレージのシステムに遅延（メール配信の遅れなど）が発生していないかを、定期的に自動テストして監視・記録するツールです。

**機能（何をしているか）**
- 設定された時間帯（8:00〜19:00など）に、15分間隔で自動的にBizストレージへテスト用ファイルをアップロードして送信します。
- 送信後、POP3通信で受信サーバーを監視し、通知メールが届くまでの時間を計測します。
- 計測結果（遅延秒数やエラー有無）をCSVファイル（`evidence_log.csv`）としてデスクトップのログフォルダに記録します。

**使い方（どう使うか）**
- 実行するとバックグラウンド（またはコマンドプロンプト上）で常駐し、自動でテストと監視を繰り返します。稼働時間外になると自動で待機状態になります。

### 3. Workmemo.py
**用途（何のためにあるか）**
SEの日常的な作業内容や費やした時間を簡単に記録し、業務の可視化とレポート（報告書）作成を行うためのツールです。

**機能（何をしているか）**
- **記録機能:** 作業の「開始」と「完了」ボタンを押すことで、実作業時間を自動計測し、カテゴリや対応内容とともにCSVへ保存します。
- **履歴呼出:** 過去の作業履歴から類似の入力を呼び出すことができます。
- **分析・レポート:** 蓄積したデータをもとに、「ジャンル別」「部署別」の円グラフを表示したり、業務報告書（グラフ付きのExcelファイル）をワンクリックで生成します。

**使い方（どう使うか）**
1. スクリプトを実行し、初回は歯車マークから自身の名前や部署を設定します。
2. 作業を始める際に「開始」を押し、作業が終わったら内容を入力して「完了・保存 (Ctrl+Enter)」を押します。
3. 報告書が必要なタイミングで「📊集計・分析(レポート)」ボタンからExcelを出力します。

### 4. audit_log_exporter.py
**用途（何のためにあるか）**
PC上で重要なファイルにアクセスした履歴（誰がどのファイルを開いたか）を監視し、監査ログとして共有サーバー（NAS）に保存するバックグラウンドツールです。

**機能（何をしているか）**
- Windowsのセキュリティイベントログ（イベントID 4663：ファイルシステムへのアクセス）を定期的に抽出します。
- `chrome.exe`, `msedge.exe`, `thunderbird.exe` などの特定のアプリケーションがファイルを読み取った操作だけをフィルタリングし、CSV形式でNASに追記保存します。
- NASがオフラインの場合はローカルにキャッシュし、次回接続時にまとめて送信します。

**使い方（どう使うか）**
- タスクスケジューラ等に登録して裏側で定期実行（数十分おきなど）させるか、常駐化させて使用します。

### 5. auto_manual_creator.py
**用途（何のためにあるか）**
パソコン上での操作手順を自動で記録し、見やすいPowerPoint形式の業務マニュアルを全自動で生成する画期的なツールです。

**機能（何をしているか）**
- 実行中、マウスクリックやキーボード入力を検知し、その瞬間のスクリーンショットを取得します。
- 画面内のどの要素をクリックしたかを解析し（例：「〇〇ボタンをクリック」）説明文言と赤枠を自動生成します。
- 終了時に、表紙、目次、業務フロー図、各手順のスクリーンショット（画像とテキストがレイアウトされたスライド）を含むPPTXファイルを出力します。

**使い方（どう使うか）**
1. スクリプトを起動し、マニュアルのタイトルや保存先などの設定を行い、「キャプチャ開始」をクリックします。
2. 普段通りにマニュアル化したい一連の操作を行います。
3. 終わったらキーボードの `[F12]` キーを押します。
4. プレビュー画面が開くので、不要な操作を削除したり文言を修正し、「PowerPointを出力」ボタンを押します。

### 6. make_v2.py / patch.py
**用途（何のためにあるか）**
主に開発者向けの「ソースコード生成・修正（ビルド）スクリプト」です。バウンスメール解析ツールをアップデートするために使われています。

**機能（何をしているか）**
- `make_v2.py`: 既存のスクリプト（`Bounce_Detailed_Analyzer.py`）を読み込み、文字列置換を使って Gemini API を呼び出す関数やExcel出力の列追加コードを自動で差し込み、統合版の `_V2_API.py` を作り出します。
- `patch.py`: 生成された `_V2_API.py` の特定の行（メイン関数の部分）を、新しいコードに丸ごと書き換えて修正（パッチ当て）します。

**使い方（どう使うか）**
- 開発環境で `python make_v2.py` を実行し、続いて `python patch.py` を実行することで、最新のバウンスメール解析ツールが生成されます。

### 7. antigravitytest.py
**用途（何のためにあるか）**
Excelファイルのデータを、別のExcelファイルへ完全にコピーする処理を検証するためのテスト用スクリプトです。

**機能（何をしているか）**
- `openpyxl`ライブラリを使用し、元となるExcelファイルの「すべてのシート」と「すべてのセルの値」を、新しく作成したExcelファイルにそっくりそのまま転記する `copy_excel_data` 関数を持っています。

**使い方（どう使うか）**
- 現状は関数が定義されているだけなので、末尾に実行用のコード（ファイルパスの指定など）を書き加えてから実行してテストします。
