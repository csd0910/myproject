# 環境同期の手順（複数PC開発用）

別のPCで開発を続けたり、新しいライブラリを追加したりする際の標準的な流れをまとめます。

## 1. ライブラリを追加・更新したとき（現在のPCで実行）
「新しい材料をリストに書き、相手に送る」イメージです。

1.  **お買い物表を更新する（レシピを書く）**:
    ```powershell
    pip freeze > requirements.txt
    ```
    - **イメージ**: 今使っている調味料をリストアップして、紙（レシピ）に書き出す作業です。
2.  **リストを発送する（Gitへのプッシュ）**:
    ```powershell
    git add requirements.txt
    git commit -m "Update libraries"
    git push origin main
    ```
    - **イメージ**: 書き出したリストを封筒に入れ、郵便局（GitHub）から相方のPCへ送る作業です。

## 2. 別のPCでそれを受け取るとき
「届いたリストを見て、スーパーに買い出しに行く」イメージです。

1.  **最新のリストを受け取る**:
    ```powershell
    git pull origin main
    ```
    - **イメージ**: 郵便ポストを確認し、最新の「お買い物表」を受け取る作業です。
2.  **材料を一括で揃える（インストール）**:
    ```powershell
    pip install -r requirements.txt
    ```
    - **イメージ**: リストを持ってスーパー（インターネット）へ行き、必要な材料を全てカゴに入れて揃える作業です。

---

## 開発の鉄則
-   **コード（.py）を書いたらプッシュする**
-   **ライブラリを入れたら `requirements.txt` もプッシュする**

この2つをセットで行うことで、どのPCでも「全く同じ環境」で開発を再開できます。
