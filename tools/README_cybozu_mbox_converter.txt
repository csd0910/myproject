サイボウズ抽出ログ → MBOX変換ツール (Thunderbird/Gmail等向け)
========================================================

■ 概要
本ツールは、サイボウズから抽出済みのメールテキスト（Eメール・社内メール）のフォルダを読み込み、
Thunderbirdなどの一般的なメールソフトや、Gmail等のIMAPサーバーと自動同期可能な「MBOX形式（.mbox）」に変換するツールです。

■ 特徴
1. 100%の互換性と正確性
　テキストファイル内の「【差出人】」「【宛先】」「【日時】」を正確に分析し、
　Thunderbirdがエラーを起こさずに読み込める完璧なRFC 5322形式のヘッダーを作成します。
2. Thunderbirdのインポートエラー回避対応済み
　メールアドレスを含まない純粋な日本語の名前だけ（例： 伊藤健人）が存在した場合でも、
　Thunderbirdの拡張機能（ImportExportTools NG等）がエラー落ちしないよう、自動で安全対策（ダミーアドレスによるラップ）を行います。
3. トラブルの多い社内UIテキストの自動除去機能
　サイボウズ特有のUIテキスト（「アドレス帳に登録する」など）がログに混入していても対象部分のみを自動でスナイプ消去します。

■ 使い方
1. 「cybozu_mbox_converter.exe」をダブルクリックで起動します。
2. ご自身のダミーメールアドレス（@以降が組織ドメインのものなど）や、ご自身の表示名（例： 自分の名前）を設定します。
3. 「変換元フォルダの選択」ボタンを押し、サイボウズから抽出済みのテキストファイル（.txt）が保存されているフォルダを選択します。
4. 自動的に同フォルダ内に「cybozu_sent_migration.mbox」というファイルが生成されます。

■ メールの取り込み（Thunderbirdへのインポート手順）
1. Thunderbirdを起動し、左側のツリー最下部にある「ローカルフォルダー」の上で右クリックして「新しいフォルダー」を適当な名前（移行用など）で作ります。
2. 作成したフォルダー上で右クリックし、「ImportExportTools NG」等を使用して、出来上がった .mbox ファイルを指定してインポートします。
3. インポートが完了したら、入ってきたメールを一覧でクリックして「Ctrl + A」ですべて全選択します。
4. 選択したままドラッグし、同期させたいクラウドフォルダ（Gmailの「送信済み」など）に落とす（ドロップする）ことで完全同期されます。

※ 注意：Thunderbirdの一覧画面で「自分が送ったはずのメールに、相手の名前が表示されている」という場合は、Thunderbirdの表示列がスマー卜表示の「通信相手」に設定されているためです。列のタイトルを右クリックして、「差出人」の列を表示させることで自己名が表示されます。

■ 動作環境
- Windows 10/11
- 外部への通信は一切行わず、すべての変換・分析処理はオフラインで安全に完結します。
